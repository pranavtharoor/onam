# Onam Sadhya — an invitation

A cinematic, scroll-driven Onam celebration and Sadhya invitation.
React + Vite + TypeScript, GSAP/ScrollTrigger, Lenis, SVG and Canvas. Static site.

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # → dist/ (deploy anywhere static)
```

- Creative brief, directions and storyboard: [`docs/creative/BRIEF.md`](docs/creative/BRIEF.md)
- How the project is built and reviewed: [`CLAUDE.md`](CLAUDE.md)
- Assets conventions: [`src/assets/README.md`](src/assets/README.md)

QA tooling needs Chromium for Playwright (`npx playwright install chromium` on a
local machine) and optionally `ffmpeg` for video work.
